## 1. 决策标识

| 字段 | 值 |
| --- | --- |
| decisionId | `C4.5` |
| 事项 | 同一检查连续失败的重试上限（ROADMAP 默认 3 次）：只计实际运行过的失败（未启动的失败不计）、通过后清零、重置走 A3 操作者通道（Worker 自己不能重置）、等待审批不计数；超过上限后按固定格式报 blocked |

| 适用轮次 | 未定（负责人批准时填写） |

## 2. 证据来源（甲提供）

- **假设**：避免同一检查无限重试浪费预算，同时不误杀「波动后可恢复」的合理重试。
- **合法用例**：操作者在达到上限后重置计数，随后重新运行并继续；等待审批的时长不进入失败计数。
- **开发集误拦率**：达到上限但本可在下一次成功的比例；检查波动导致连续失败的分布。
- **副作用观察**：达到上限后 Worker 是否按固定格式报 blocked（卡住的验收项、每次尝试改了什么、检查输出要点、判断原因、需要谁做什么决定）；是否出现绕过检查的行为。
- **宿主能力证据**：检查运行结果事件能否稳定获得；重置是否只能由操作者执行；blocked 报告格式是否被宿主接受。
- **证据缺口**：以上全部待甲提供；当前无 A3 重置通道验证、无开发集重试分布。

## 3. 选项

| 选项 | 说明 | 风险/成本 |
| --- | --- | --- |
| A. 维持关闭（默认） | 不计数、不拦截 | 无新增风险；可能无限重试浪费预算 |
| B. 上限 3（ROADMAP 默认） | 连续失败 3 次后 blocked | 波动任务可能被过早停止 |
| C. 其它上限（负责人指定） | 按开发集分布选择 | 需要证据支撑数值 |
| D. 仅提示 | 记录次数，不拦截 | 不阻断；预算风险仍在 |

## 4. 影响

- 对 B 线指标：影响 G3 交付完成率与成本；错误计数会污染 D4。
- 对样本量/成本/可比性：提前停止会减少有效运行并影响样本量；必须与 PREREG 样本量规则一致。
- 开发者摩擦：需要人工重置与 blocked 报告。
- 失败语义：超过上限 → blocked（不是 failed）；重置后继续；等待审批不计入计数（若 C3 启用）。
- 回滚：计数与拦截可关闭；既有运行记录保留。
