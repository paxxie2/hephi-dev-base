## 2. 证据来源（甲提供）

- **假设**：降低任务卡准备成本与审查阅读成本，提升日常可用性（不直接构成 B 线效果）。
- **合法用例**：一个合法任务卡通过 lint-task 无错误提示；summary 能按验收项分组呈现改动与计划；模板被实际用于新任务。
- **开发集误拦率**：lint-task 误报（合法卡被判为「范围过宽/验收项过多」）比例；summary 遗漏改动的情况。
- **副作用观察**：提示过多导致忽略；summary 与真实 diff 不一致；模板维护成本。
- **项目能力证据**：CLI 子命令接入方式；任务卡 schema 校验能力；summary 所需数据（计划 C4.2、覆盖提示 C2）是否可用。
- **证据缺口**：以上全部待甲提供；C2/C4.2 未批准时 summary 只能部分实现。

## 3. 选项

| 选项 | 说明 | 风险/成本 |
| --- | --- | --- |
| A. 维持关闭（默认） | 不实现任何便利功能 | 无新增风险；准备/审查成本维持 |
| B. 仅 Issue 模板 | 提供模板与写法建议 | 成本最低；效果不可机械测量 |
| C. lint-task | 离线校验任务卡并提示 | 误报风险；维护成本 |
| D. summary | 按验收项分组 + 计划 + 覆盖提示 | 依赖 C2/C4.2；实现成本最高 |
| E. 组合（负责人指定） | 按实际需要选择 | 需逐项验收 |

## 4. 影响

- 对 B 线指标：不直接影响 D2/D4/D5 判定；只影响准备与审查效率。
- 对样本量/成本/可比性：降低准备成本可能间接影响任务集规模；不得据此声称 B 线收益。
- 开发者摩擦：减少手工整理；模板被误用可能产生形式化任务卡。
- 失败语义：lint-task 只提示，不阻塞 prepare；summary 不写 PR、不产生结论。
- 回滚：CLI 可移除；模板可回滚；既有任务保留。
